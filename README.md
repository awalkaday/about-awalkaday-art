# about: awalkaday.art
> Code repository for the **About** page of **awalkaday.art** web gallery. 

This is a webpage that used to describe in detail the history of the photo collection.   
It consists of a descriptive page, mainly written in third person, which is available in 3 languages: **English**, **French**, and **Mandarin Chinese**.
